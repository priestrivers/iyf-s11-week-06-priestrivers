## Project Description

This project demonstrates asynchronous programming in JavaScript using callbacks, promises, and async/await. It also explores working with APIs using the Fetch API. The main project is a Weather Dashboard that retrieves real-time weather information from the OpenWeatherMap API and displays it in a clean, user-friendly interface.

## Technologies Used

* HTML5
* CSS3
* JavaScript (ES6)
* Fetch API
* OpenWeatherMap API
* Local Storage
* Git
* GitHub
* Visual Studio Code

## Features

* Demonstrates synchronous and asynchronous JavaScript.
* Implements callbacks, promises, and async/await.
* Fetches weather data from the OpenWeatherMap API.
* Displays the city name, weather icon, temperature, weather description, feels-like temperature, humidity, wind speed, and pressure.
* Handles invalid city names and network errors.
* Shows a loading indicator while fetching weather data.
* Saves the last five searched cities using Local Storage.
* Allows users to click a previous search to display the weather again.

## How to Run

1. Clone the repository:

   ```bash
   git clone https://github.com/priestrivers/iyf-s11-week-06-priestrivers.git
   ```

2. Navigate into the project folder:

   ```bash
   cd iyf-s11-week-06-priestrivers
   ```

3. Open the project in Visual Studio Code.

4. Open the `weather-dashboard` folder.

5. Ensure your OpenWeatherMap API key is added to `app.js`.

6. Open `index.html` in your browser or run it using the Live Server extension in Visual Studio Code.
